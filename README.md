# CreatorCut Studio

브라우저에서 도는 영상·음원 편집기입니다. 설치 없이 열어서 촬영분을 가져오고, 타임라인에서 자르고 순서를 잡고, 목소리를 녹음해 얹은 다음, **파일로 내보낼 수 있습니다.**

작업 메뉴는 두 개입니다.

| 메뉴 | 하는 일 |
| --- | --- |
| **동영상 편집** | 미디어 라이브러리 · 프로그램 모니터 · 속성 패널 · 하단 멀티트랙 타임라인 |
| **음원 편집** | 오디오 라이브러리 · 파형 편집기 · 마이크 녹음과 입력 레벨 미터 |

두 메뉴는 같은 프로젝트를 씁니다. 음원 편집에서 다듬은 오디오가 동영상 타임라인의 오디오 트랙에 그대로 나타납니다.

## 실행 환경

Node.js 22 이상과 pnpm 10 이상이 필요합니다. Node.js가 설치되어 있다면 Corepack으로 pnpm을 활성화할 수 있습니다.

```bash
corepack enable
corepack prepare pnpm@10.15.1 --activate
```

## 로컬에서 실행하기

압축을 해제한 폴더에서 아래 명령을 순서대로 실행합니다.

```bash
pnpm install
pnpm dev
```

명령어가 표시하는 로컬 주소(일반적으로 `http://localhost:3000`)를 브라우저에서 엽니다. 녹음 기능을 사용하려면 브라우저의 마이크 접근 권한을 허용해야 합니다.

## 프로덕션 빌드 및 실행

배포 전에는 아래 명령으로 타입 검사와 빌드를 실행합니다.

```bash
pnpm check
pnpm build
pnpm start
```

`pnpm start`는 기본적으로 `http://localhost:3000`에서 정적 빌드 결과를 제공합니다.

## 주요 스크립트

| 명령 | 용도 |
| --- | --- |
| `pnpm dev` | Vite 개발 서버 실행 |
| `pnpm check` | TypeScript 타입 검사 |
| `pnpm build` | 프런트엔드와 정적 서버용 프로덕션 빌드 |
| `pnpm start` | 빌드된 프로젝트 실행 |
| `pnpm format` | Prettier로 소스 코드 포맷팅 |

## 할 수 있는 일

### 동영상 편집
- 좌측 브라우저 탭: **미디어 / 오디오 / 텍스트**
- **다중 트랙 타임라인** — 트랙(행)을 직접 **추가·삭제**합니다. 툴바의 `트랙 +영상/+오디오/+자막`, 또는 트랙 목록 맨 아래 `트랙 추가` 행. 각 행에 음소거·잠금·삭제 버튼이 있고 삭제는 Ctrl+Z로 되돌립니다. 새 영상 트랙은 위에 쌓여 오버레이가 됩니다
- 클립을 **위아래로 끌어 다른 트랙으로** 이동, 좌우로 끌어 위치 이동, 가장자리를 끌어 트리밍 (재생 헤드·다른 클립 끝에 **스냅**)
- 재생 헤드에서 나누기, 복제, 삭제, 실행 취소/다시 실행
- **화면 배치** — 전체 / 좌우 절반 / 상하 절반 / 작은 화면(PIP). 크기·위치·불투명도 개별 조절
- **색 보정** — 밝기 · 대비 · 채도 · 색조
- **전환 효과** — 시작·끝 각각 디졸브 / 페이드(검은 화면), 길이 조절
- **자막** — 툴바 `자막 넣기` 버튼, 또는 좌측 `텍스트` 탭
  - 프리셋 3종: 기본 자막 / 큰 제목 / 강조
  - **글꼴 5종**: 기본 · 굵은 고딕 · 명조 · 손글씨 · 모노
  - 내용(여러 줄) · 크기 · 굵기(보통/굵게/아주 굵게) · 글자 색 · 정렬
  - **배경과 테두리**: 상자 / 외곽선 / 그림자, 색과 진하기, 외곽선 두께
  - **배치**: 빠른 위치(위·가운데·아래), 가로/세로 위치, 기울이기(−45°~45°)
  - **간격과 시간**: 줄 간격, 자간, 표시 시간
  - **이 모양을 모든 자막에 적용** — 자막 파일을 가져온 뒤 하나만 꾸미면 전부에 반영
  - **.srt · .vtt 자막 파일 가져오기** — 타이밍 그대로 자막 클립이 한 번에 만들어집니다
  - `넣은 자막` 목록에서 클릭하면 그 지점으로 이동합니다
- 클립별 볼륨, 재생 속도(0.5~2x), 오디오 페이드 인/아웃
- 클립 안 필름스트립 썸네일, 오디오 파형

### 음원 편집
- 여러 파형을 **레인으로 쌓아 동시에 편집**
- 파형 행(트랙)을 직접 **추가·삭제**, 행마다 음소거·잠금·삭제
- 마이크 녹음 + 실시간 입력 레벨 미터
- **소리 효과** — 에코 · 공간감(리버브) · 먹먹하게(로우패스) · 얇게(하이패스), 세기 조절
- 볼륨, 페이드 인/아웃, 나누기, 복제, 삭제

### 편집 도구 (현업에서 많이 쓰는 것들)

- **무음 자동 컷** — 말하는 영상에서 조용한 구간을 찾아 잘라내고 뒤를 당깁니다. 앞뒤로 약간의 여유를 남겨 말이 잘리지 않습니다 (Premiere의 무음 감지 / CapCut 자동 컷에 해당)
- **비트 찍기 + 비트에서 자르기** — 음악의 타점을 찾아 타임라인에 마커로 찍고, 그 지점에서 모든 클립을 한 번에 자릅니다 (음악 싱크 편집)
- **목소리에 맞춰 낮추기(덕킹)** — 다른 트랙에서 소리가 나는 동안 이 클립만 자동으로 작아집니다. 미리보기와 내보내기가 같은 곡선을 씁니다 (Premiere Essential Sound의 자동 더킹)
- **볼륨 자동 맞춤** — 가장 큰 소리가 기준에 닿도록 한 번에 올립니다
- **움직임 프리셋** — 천천히 확대 / 천천히 축소 / 왼쪽·오른쪽으로 / 펀치 인. 사진에 걸면 켄번즈 효과가 됩니다
- **자막 등장 효과** — 팝 / 떠오르기 / 타이핑
- **정지 화면** — 재생 위치의 화면을 정지컷으로 만들어 그 자리에 끼워 넣습니다. 클립을 잘라 넣으므로 뒤 내용이 밀립니다
- **출력 비율** — 가로 16:9 / **쇼츠 9:16** / 정사각 1:1. 미리보기와 내보내기가 함께 바뀝니다

### 내보내기
WebCodecs로 **mp4(H.264 + AAC)** 를 직접 인코딩합니다.

- **실시간보다 빠릅니다.** 사진·자막 구간은 거의 즉시, 영상 구간은 프레임당 한 번 탐색합니다
- **길이 정보가 정확하고 파일 내 탐색이 됩니다** (검증: 5초 영상 → 길이 5.10초 인식, 3초 지점 정확히 탐색)
- 화면 배치·색 보정·전환·자막·소리 효과가 **모두 파일에 반영**됩니다. 미리보기와 내보내기가 같은 렌더 코드를 씁니다
- 소리는 OfflineAudioContext로 한 번에 믹스하므로 오디오가 속도를 잡아먹지 않습니다
- WebCodecs가 없는 브라우저에서는 기존 실시간 webm 녹화 방식으로 자동 전환합니다

## 제약

- 내보내기 속도는 내용에 따라 다릅니다. 영상 트랙이 많을수록 프레임마다 트랙 수만큼 탐색이 필요해 느려집니다.
- 프로젝트는 저장되지 않습니다. 새로고침하면 처음부터 시작합니다(설계상 의도).
- 피치 보정, 노이즈 제거 같은 고급 오디오 처리는 없습니다.
- 키프레임 애니메이션(시간에 따라 변하는 위치·크기)은 없습니다. 값은 클립 전체에 일정하게 적용됩니다.
- 크로마키(그린스크린), 마스크는 없습니다.

## 스크롤 동작

타임라인과 파형 편집기는 **자기 영역 안에서만** 스크롤합니다. 페이지나 주변 패널은 밀리지 않습니다.

- 세로로 스크롤해도 **시간 눈금이 위에 고정**됩니다
- 가로로 스크롤해도 **트랙 이름 열이 왼쪽에 고정**됩니다
- 트랙이 많아지면 그 영역 안에 세로 스크롤바가 생깁니다

## 반응형 정책

가로 스크롤은 어느 폭에서도 발생하지 않습니다. 900px 아래에서는 2단이 1단으로 접히고 미리보기가 맨 위로 올라옵니다. 520px 아래에서는 소리 버튼이 세로로 쌓이고 볼륨 슬라이더가 숨겨집니다(기기 볼륨으로 대체).
