# ClipForge

브라우저에서 도는 영상·음원 편집기입니다. 설치 없이 열어서 촬영분을 가져오고, 멀티트랙 타임라인에서 자르고 배치하고, 자막을 얹고, 목소리를 녹음한 다음 **mp4 파일로 내보냅니다.**

> 앱 화면에는 `CreatorCut`으로 표시됩니다. 저장소 이름과 다르니 한쪽으로 통일하려면 알려 주세요.

서버로 파일을 올리지 않습니다. 디코딩·합성·인코딩이 전부 브라우저 안에서 끝납니다.

작업 메뉴는 두 개이고, 같은 프로젝트를 공유합니다.

| 메뉴 | 구성 |
| --- | --- |
| **동영상 편집** | 미디어 브라우저 · 프로그램 모니터 · 속성 패널 · 하단 멀티트랙 타임라인 |
| **음원 편집** | 여러 파형을 레인으로 쌓은 편집기 · 마이크 녹음과 입력 레벨 미터 |

음원 편집에서 다듬은 오디오가 동영상 타임라인의 오디오 트랙에 그대로 나타납니다.

---

## 빠른 시작

```bash
git clone https://github.com/YimJunsu/media-workbench-ClipForge.git
cd media-workbench-ClipForge
pnpm install
pnpm dev
```

표시되는 주소(보통 `http://localhost:3000`)를 브라우저에서 엽니다.

`npm install && npm run dev` 로도 동작합니다. 저장소에 `pnpm-lock.yaml`과 `package-lock.json`이 모두 있으니 한 가지를 정해 쓰시면 됩니다.

### 요구 사항

- **Node.js 22 이상**
- **Chrome 또는 Edge 권장** — mp4 내보내기가 WebCodecs를 씁니다. 없는 브라우저에서는 실시간 webm 녹화 방식으로 자동 전환됩니다
- 녹음을 쓰려면 브라우저에서 마이크 권한을 허용해야 합니다

### 스크립트

| 명령 | 용도 |
| --- | --- |
| `pnpm dev` | Vite 개발 서버 |
| `pnpm check` | TypeScript 타입 검사 |
| `pnpm build` | 프런트엔드 + 정적 서버 프로덕션 빌드 |
| `pnpm start` | 빌드 결과 실행 |
| `pnpm format` | Prettier 포맷팅 |

## 기능

### 타임라인

- **다중 트랙** — 영상·오디오·자막 트랙을 원하는 만큼 추가·삭제. 행마다 음소거·잠금·삭제
- 클립을 **위아래로 끌어 다른 트랙으로**, 좌우로 끌어 위치 이동, 가장자리를 끌어 트리밍
- 재생 헤드와 다른 클립 끝에 **자석처럼 스냅**
- 나누기 · 복제 · 삭제 · 실행 취소/다시 실행 (`Ctrl+Z` / `Ctrl+Shift+Z`)
- 클립 안에 **실제 프레임을 뽑은 필름스트립**, 오디오는 디코딩한 **파형**
- 세로 스크롤에도 시간 눈금이, 가로 스크롤에도 트랙 이름이 고정됩니다

### 화면과 색

- **화면 배치** — 전체 / 좌우 절반 / 상하 절반 / 작은 화면(PIP). 새 영상 트랙은 위에 쌓여 오버레이가 됩니다
- **움직임 프리셋** — 천천히 확대·축소, 좌우 팬, 펀치 인. 사진에 걸면 켄번즈 효과
- **색 보정** — 밝기 · 대비 · 채도 · 색조
- **전환 효과** — 시작·끝 각각 디졸브 / 페이드
- **정지 화면** — 재생 위치를 정지컷으로 만들어 클립을 잘라 끼워 넣습니다
- **출력 비율** — 가로 16:9 / **쇼츠 9:16** / 정사각 1:1

### 자막

- 프리셋 3종, **글꼴 5종**(기본·굵은 고딕·명조·손글씨·모노)
- 크기 · 굵기 · 색 · 정렬 · 가로/세로 위치 · 기울이기 · 줄 간격 · 자간
- 배경: **상자 / 외곽선 / 그림자** — 색과 진하기, 외곽선 두께
- **등장 효과** — 팝 / 떠오르기 / 타이핑
- **.srt · .vtt 가져오기** — 타이밍 그대로 자막 클립이 한 번에 생성
- **이 모양을 모든 자막에 적용** — 자막 수십 개를 하나만 꾸며 일괄 반영

### 오디오

- 여러 파형을 레인으로 쌓아 동시에 편집, 마이크 녹음 + 실시간 레벨 미터
- 클립별 볼륨 · 페이드 인/아웃 · 재생 속도(0.5~2x)
- **소리 효과** — 에코 · 공간감 · 먹먹하게 · 얇게
- **무음 자동 컷** — 조용한 구간을 찾아 잘라내고 뒤를 당깁니다. 앞뒤로 여유를 남겨 말이 잘리지 않습니다
- **비트 찍기 + 비트에서 자르기** — 음악 타점을 마커로 찍고 그 지점에서 일괄 분할
- **목소리에 맞춰 낮추기(덕킹)** — 다른 트랙이 울릴 때 이 클립만 자동으로 작아집니다
- **볼륨 자동 맞춤**

### 내보내기

WebCodecs로 **mp4(H.264 + AAC)** 를 직접 인코딩합니다.

- **실시간보다 빠릅니다.** 사진·자막 구간은 거의 즉시, 영상 구간은 프레임당 한 번 탐색
- **길이 정보가 정확하고 파일 내 탐색이 됩니다**
- 배치·색 보정·전환·자막·소리 효과가 **모두 파일에 반영**됩니다 — 미리보기와 내보내기가 **같은 렌더 코드**(`editor/render.ts`)를 쓰기 때문입니다
- 소리는 `OfflineAudioContext`로 한 번에 믹스해 오디오가 속도를 잡아먹지 않습니다

## 구조

```
client/src/
  pages/Home.tsx        셸, 두 작업 메뉴, 내보내기 실행
  editor/
    model.ts            프로젝트 모델, 파형·비트·무음 분석, 자막 파싱
    useEditor.ts        상태 + 실행취소 히스토리 + 재생 엔진 + 오디오 그래프
    render.ts           한 프레임 렌더러 (미리보기와 내보내기가 공유)
    Timeline.tsx        멀티트랙 타임라인
    VideoWorkspace.tsx  동영상 편집 화면
    AudioWorkspace.tsx  음원 편집 화면
    exportMp4.ts        WebCodecs 인코딩 + 오프라인 오디오 믹스
    Preview.tsx         캔버스 프로그램 모니터
  index.css             다크 편집 테마
server/index.ts         빌드 결과를 제공하는 최소 정적 서버
```

### 설계 메모

**재생 시계는 화면에 있는 영상이 갖습니다.** 실제 영상 파일은 바깥 타이머에 끌려다니면 디코더가 멈추고 화면이 검게 나옵니다. 그래서 영상이 매끄럽게 재생되는 동안에는 그 요소가 시계가 되고, 벽시계는 사진·자막·빈 구간만 담당합니다.

**미리보기와 내보내기는 같은 `drawFrame` 하나를 씁니다.** 화면에서 본 것과 파일이 어긋날 수 없는 구조입니다.

## 아직 없는 것

- **프로젝트 저장** — 새로고침하면 처음부터 시작합니다 (설계상 의도)
- **키프레임 애니메이션** — 값이 클립 전체에 일정하게 적용됩니다. 움직임은 시작→끝 프리셋으로 대신합니다
- **크로마키(그린스크린), 마스크**
- **피치 보정, 노이즈 제거**
- 내보내기 속도는 내용에 따라 다릅니다. 영상 트랙이 많을수록 프레임마다 트랙 수만큼 탐색이 필요해 느려집니다

## 반응형

가로 스크롤은 어느 폭에서도 발생하지 않습니다. 900px 아래에서는 2단이 1단으로 접히고 미리보기가 맨 위로 올라옵니다. 520px 아래에서는 소리 버튼이 세로로 쌓이고 볼륨 슬라이더가 숨겨집니다.
